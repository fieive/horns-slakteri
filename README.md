# Horns Slakteri – nettsideforslag (v2)

Designforslag fra ON—PAN, bygget fra Figma-fila «nettside-design-leads» (v1 «to veier», desktop 200:1829 og mobil 201:1829. «Meld inn dyr» (meld-inn.html) er skjemaet fra v2 (212:1829)).
Statisk HTML/CSS/JS, ingen byggesteg. Siden er merket `noindex` og har en stripe øverst om at den er et forslag.

- `index.html` – hele siden
- `style.css` – farger og fonter (Gloock + DM Serif Display for ø og tankestrek, Schibsted Grotesk)
- `skjema.js` – «Meld inn dyr»: legg til dyr og behandlinger, ja/nei på medisinbruk. Sender ingenting ennå.

Avklares med Horns før noe blir ekte: stiftelsesår, tall fra 2016, rettigheter til strandbildet, vektorlogo, mottaker for skjemaet.
